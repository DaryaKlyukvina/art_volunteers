# ArtVolunteers — сервис поиска волонтёров для арт-мероприятий

## Назначение
Консольное (в перспективе — веб-) приложение, которое соединяет организаторов
арт-мероприятий (арт-маркетов, ярмарок мастеров, выставок) с волонтёрами,
готовыми помочь в их проведении: встреча гостей, помощь мастерам,
логистика, фотосъёмка и т.д.

## Целевая аудитория
- организаторы арт-маркетов и ярмарок, которым нужны волонтёры на мероприятие;
- волонтёры, которые хотят участвовать в проведении творческих событий и
  выбирают мероприятия по дате, месту и нужным навыкам.

## Предметная область
Сервис хранит информацию об организациях-организаторах, мероприятиях, которые
они проводят, волонтёрах и их регистрациях на конкретные мероприятия.
Для каждого мероприятия известно, сколько волонтёров требуется, и сервис
не допускает регистрацию сверх этого количества или повторную регистрацию
одного волонтёра на одно и то же мероприятие.

## Основные сущности
- **Организация (организатор)** 
вааппа
— организация или частное лицо, проводящее
  арт-мероприятие (название, контакт).
- **Мероприятие**

 — арт-маркет, ярмарка и т.п. (название, организатор, дата,
  место, требуемое число волонтёров).
- **Пользователь (волонтёр)** 

— человек, готовый помогать на мероприятиях
  (имя, контакт, навыки).
- **Регистрация**

 — связь волонтёра с конкретным мероприятием.

## Основные функции
- добавление и поиск организаций, мероприятий и волонтёров;
- просмотр списка мероприятий, отсортированного по дате;
- отбор мероприятий по дате и волонтёров по навыку;
- проверка количества свободных мест волонтёров на мероприятии;
- регистрация волонтёра на мероприятие и отмена регистрации;
- сохранение и загрузка всех данных в JSON-файлах.

## Формат хранения данных
Все данные хранятся в формате JSON в каталоге `data/`. Организации, мероприятия
и волонтёры хранятся как списки словарей с полем `id`; при загрузке в программе
они превращаются в словари `{id: запись}` для быстрого поиска. Регистрации
хранятся как список словарей `{id, event_id, volunteer_id}`.

## План развития
- ПР3 — сущности переработаны в классы (Event, User, Organization,
  Registration), инкапсуляция и наследование;
- ПР5–ПР6 — веб-приложение на Django, отображение мероприятий на страницах;
- ПР7, ПР9 — модели Django, база данных, ORM, админ-зона;
- ПР10 — формы регистрации на мероприятие и создания мероприятия;
- ПР11 — регистрация/аутентификация пользователей, разделение ролей
  «волонтёр» и «организатор»;
- ПР13–ПР15 — автоматизированное тестирование Django-приложения;
- в дальнейшем — REST API и развёртывание в Docker.

## История разработки
- **ПР1** — выбрана тема, создан репозиторий, реализован начальный сценарий
  на простых переменных (см. `pr1_initial_script.py`).
- **ПР2** — данные переведены в коллекции (словари и списки), код разбит на
  модули, добавлены обработка исключений, хранение данных в JSON,
  автотесты pytest, аннотации типов.
