# ArtVolunteers — платформа волонтёров для арт-мероприятий

## О проекте
Django-сайт, который помогает посетителям находить актуальные арт-мероприятия,
переходить на внешние сервисы покупки билетов и подавать заявки на волонтёрство.
Организаторы рассматривают заявки и принимают или отклоняют кандидатов.

## Роли
- **Гость:** просматривает и ищет опубликованные будущие мероприятия, страницы организаций.
- **Пользователь/волонтёр:** регистрирует аккаунт, отправляет одну заявку на мероприятие,
  видит её статус в личном кабинете.
- **Сотрудник организации:** видит заявки только своей организации и принимает/отклоняет их.
- **Администратор сайта:** через Django Admin добавляет организации, сотрудников,
  категории и мероприятия.

Для отправки заявки необходим вход в аккаунт. Для доступа сотрудника к заявкам
администратор добавляет пользователя в раздел «Сотрудники организаций».

## Основные модели
- `User` — встроенная модель Django.
- `Organization` — организатор.
- `OrganizationMember` — связь сотрудника с организацией и проверка доступа.
- `Category` — категория мероприятий, управляется администратором.
- `Event` — мероприятие, в том числе внешняя ссылка `ticket_url`.
- `VolunteerApplication` — заявка пользователя с контактами, опытом и статусом
  `pending`, `accepted` или `rejected`.

Повторная заявка одного пользователя на одно мероприятие запрещена ограничением БД.
Число принятых заявок ограничено значением `volunteers_needed`.

## Установка и запуск
Рекомендуется Python 3.11+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python manage.py makemigrations organizations events applications
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Откройте `http://127.0.0.1:8000/`. Админ-панель: `http://127.0.0.1:8000/admin/`.
Чтобы перенести организации и мероприятия из прежней JSON-версии, можно выполнить `python manage.py import_legacy_json --directory data` после миграций. Старые записи волонтёров не импортируются: теперь для заявок используются аккаунты Django.

В админ-панели сначала создайте организацию и категорию, затем пользователя-сотрудника
(или назначьте существующего) и связь в «Сотрудники организаций», после этого создайте
мероприятие и установите статус «Опубликовано».

## Структура
- `config/` — настройки проекта Django.
- `accounts/` — регистрация, вход и личный кабинет.
- `organizations/` — организации и их сотрудники.
- `events/` — категории, мероприятия, каталог и ORM-запросы для ПР9.
- `applications/` — формы, заявки, статусы и кабинет организатора.
- `templates/` — HTML-шаблоны.
- `media/` — загружаемые логотипы и изображения мероприятий.

Старые консольные модули (`main.py`, `storage.py`, `legacy_events.py`,
`legacy_organizations.py` и др.) оставлены в корне как история предыдущих этапов. Новый веб-сайт запускается через `manage.py`.
